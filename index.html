Pune robotics labHumanoid lab, from scratch

Designed NVIDIA's first robotics lab in Pune: floor layout, a roof gantry and pulley rig for the Unitree G1, and a dedicated network that fixed subnet and AP-isolation problems and stopped ROS 2 topics interfering with each other.

ElektraCustom omni-drive AMR

Built a 4-wheel omni-drive robot around Jetson AGX Thor with a 3-camera RealSense rig, to validate the cuVSLAM standalone library.

Apple to plateGR00T N on Unitree G1

Took a policy through the full pipeline: teleoperated demonstrations, GR00T N fine-tuning, LEAPP export and deployment to the Thor backpack. The G1 now picks up an apple and places it on a plate on its own.

UR10e pick and placeSim-to-real

Set up the UR10e arm in the lab and trained a pick-and-place policy with sim-to-real transfer in Isaac Lab Arena. I added the UR10e as a new embodiment in the framework.

Nova Carter test frameworkIsaac ROS on a live robot

Built an end-to-end framework that runs perception and navigation use cases on a live Nova Carter with no manual steps.

G1 Preflight CheckerAutomated startup checks

A sanity suite that runs on every G1 startup and checks camera and sensor health and Dex-3 hand status before the robot moves. I also built a test orchestrator that takes a documentation change through test planning, Jira, automation and a merge request.
